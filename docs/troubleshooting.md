# 구축 중 해결한 문제

## 1. Fail2ban이 Nginx 로그를 읽지 못하는 문제

systemd의 `ProtectHome` 설정 때문에 Fail2ban 서비스에서 필요한 로그 경로에 접근하지 못하는 문제가 있었습니다. 서비스 설정과 로그 접근 경로를 확인하고 조정했습니다.

## 2. Docker Volume 환경에서 로그 변경 감지 문제

Nginx 로그를 Docker Volume으로 연결한 환경에서 로그 파일 변경 이벤트가 예상한 방식으로 전달되지 않았습니다. 로그 파일 변경을 감지하는 방식과 컨테이너·호스트 간 마운트 경로를 확인해 감지 흐름을 조정했습니다.

## 3. UTC와 KST 시간 차이

로그 타임스탬프와 차단 판단에 사용한 시간대가 달라 Fail2ban의 차단 판단이 어긋나는 문제가 있었습니다. 시간 표현과 파싱 기준을 맞춰 점검했습니다.

## 4. 외부 AI API의 응답 시간

Gemini API 호출은 일반적인 내부 HTTP 요청보다 오래 걸릴 수 있어 Nginx Reverse Proxy Timeout 설정을 조정했습니다. 외부 API 지연과 서비스 자체 오류를 구분하는 것이 중요했습니다.
